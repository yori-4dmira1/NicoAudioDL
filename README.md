# NicoAudioDL

ニコニコ動画から音声のみを取り出し、**m4a形式・サムネイル埋め込み付き**で保存するデスクトップアプリ。
[YTAudioDL-ver5](https://github.com/yori-4dmira1/YTAudioDL-ver5) をベースにしたニコニコ動画版。

> 権利上ダウンロードが許諾されている動画（自分の投稿、ダウンロードが許可されたもの等）、および私的利用の範囲でのみ使用してください。ニコニコ動画の利用規約も確認してください。

## 使い方

1. `NicoAudioDL.exe` を起動（初回のみ数秒のセットアップ）
2. ニコニコ動画のURLを貼る（複数可・1行1件）
3. 「ダウンロード」を押す

対応URL: 動画 (`/watch/sm…`, `nico.ms/…`)、マイリスト、シリーズ、ユーザーの投稿動画一覧

## 範囲指定と時間の切り出し

- **再生リストの範囲**: マイリスト／シリーズで「n曲目〜m曲目」だけ取得（片方空欄可）。ファイル名の先頭番号は元の番号のまま。
- **切り出し**: `90` / `1:30` / `0:02:15` 形式で開始・終了を指定。名前の末尾に `[1m30s-2m45s]` が付く。
- 追加ボタンを押すと両方の入力欄は自動で空になる。

## ログインが必要な動画

ログイン必須・会員限定の動画は、次のどちらかを設定します。

- **cookies.txt**: ブラウザ拡張でNetscape形式に書き出したファイルを指定
- **ブラウザ指定**: Chrome / Firefox などを選ぶと、そのブラウザのログイン状態を利用

プレミアム会員のcookiesを使えば、会員限定の動画にも対応できます（権利・規約の範囲で）。

## ビルド

```
pip install pyinstaller
python build.py            # dist/NicoAudioDL.exe
python build.py --onedir   # 起動が速い形式
```

GitHub Actions（`Build Windows EXE`）でもビルドできます。

## 構成

| ファイル | 役割 |
|---|---|
| `app.py` | GUI本体。yt-dlpを子プロセスとして起動し進捗を解析 |
| `runtime.py` | yt-dlp / ffmpeg の展開・更新・復旧 |
| `build.py` | vendor取得とPyInstallerビルド |

## ニコニコ版での変更点

- URL判定・再生リスト判定をニコニコ用に変更（マイリスト / シリーズ / ユーザー投稿一覧）
- 音声のみの配信がない動画向けに `-f ba/b` でフォールバック
- ログイン用の cookies.txt / ブラウザ指定を追加
- ニコニコ特有のエラー（要ログイン・削除済み等）に日本語ヒントを表示
- yt-dlp の更新確認間隔を3日→1日に短縮（配信仕様の変更に追従しやすくするため）

## ライセンス上の注意
